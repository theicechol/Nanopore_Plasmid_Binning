# No-reference plasmid analysis

Inputs: pICK923/mCha Qiagen and Zymo Nanopore read preparations.

## Candidate 1

- Consensus length: 5,840 bp
- Topology: circular path recovered
- Cluster: 719 reads across both preparations
- Median 15-mer support: 94.49%
- Supporting dimer peak: 11,656 bp, 326 reads, 99% sequence containment
- E. coli K-12 exact 21-mer overlap: 19.5% (consistent with shared plasmid/backbone sequence, not a whole-host match)

## Candidate 2

- Representative length: 7,702 bp
- Topology: unresolved/linear; circular closure was not demonstrated
- Cluster: 129 reads across both preparations
- Median 15-mer support: 92.76%
- Exact 21-mer overlap with the E. coli K-12, V. natriegens ATCC 14048, and B. subtilis 168 host references: 0%

Both candidates occur independently in the Qiagen and Zymo preparations. Candidate 2
is therefore retained as a distinct plasmid-like sequence family, but its ends require
independent assembly or junction-spanning validation before it is described as circular.

The GenBank records are minimally annotated because this analysis did not use a plasmid
reference. They should not be treated as synthesis-ready or publication-grade finished
sequences without an independent assembler/polisher and feature annotation.
